# CHARMM-GUI carbohydrate-recognition investigation

Date: 2026-08-24

## Summary

An unmodified 18-chain, DP20 cellulose Iβ crystallite was intermittently
interpreted by the CHARMM-GUI carbohydrate reader as containing ten
beta-D-quinovose (`BQUI`) units. All ten assignments occurred on alternating
residues of the same input chain. The source generated by
`dynamics_cellulose` was not 6-deoxy: every affected residue contained the
complete `C6-H61-H62-O6-HO6` group, contained no `H63`, and had explicit
`C6-O6` and `O6-HO6` connectivity.

The first actual loss of `O6/HO6` and the first appearance of `H63` occurred in
the topology generated after automatic carbohydrate recognition, not in the
builder output. This distinction was established by atom-name comparison by
chain, residue, and atom rather than by residue labels or textual checksums.

The validated solution is a dedicated CHARMM-GUI input profile. It:

1. preserves every heavy atom and every carbon-bound hydrogen;
2. omits only alcohol hydroxyl-hydrogen coordinates (`HO1`, `HO2`, `HO3`,
   `HO4`, and `HO6`), allowing the selected CHARMM topology to place them;
3. writes whole residue blocks in the direction expected for
   `O4(i)-C1(i+1)` recognition; and
4. retains explicit intramolecular and beta-(1→4) `CONECT` records.

The profile is enabled explicitly with `--charmm-gui`. Standard all-atom
output remains the default.

## Evidence and localization

The original comparison involved two 18 x 20 structures, both containing 360
residues:

| Structure | Atoms | Bonds | Angles | Dihedrals |
| --- | ---: | ---: | ---: | ---: |
| Earlier intact reference | 7,614 | 7,956 | 14,778 | 23,760 |
| Misrecognized result | 7,604 | 7,946 | 14,768 | 23,730 |

In residues 2, 4, ..., 20 of segment CARM, the misrecognized result replaced
`O6 + HO6` with `H63`. This is one atom fewer per affected residue and accounts
exactly for the ten-atom difference. Searches of the generator found no BQUI,
quinovose, 6-deoxy transformation, `H63` creation, parity-dependent C6 rule, or
CARM-specific chemistry. Direct inspection instead showed intact primary
alcohols in all 360 generated residues.

Moving the suspect chain to another chain identifier moved the recognition
pattern with its coordinate block; deleting a chain identifier alone did not
remove the pattern. This excluded a hard-coded special case for the literal
name CARM. Omitting hydroxyl-H coordinates eliminated the BQUI calls, including
on the previously affected structure.

A second, independent issue was found during the experiment. Reversing only
the numeric residue labels does not change PDB record order, so CHARMM can
construct the linkage in the wrong physical direction. The resulting test had
342 nominal glycosidic bonds near 9.225 A and terminal overlaps near 0.19 A,
which explained its enormous single-point energy. The correction reverses
whole residue record blocks and then renumbers them. Manual replacement of
BQUI in the web interface was also observed to change adjacent `1→4` linkages
to `1→1`; it is therefore not the recommended repair.

The responsible project path is now centralized in
`cellulose_core.pdbio.write_pdb`: `charmm_gui=True` selects filtered atom
serialization, whole-block reverse ordering, and the corresponding
`O4(i)-C1(i+1)` bond graph. `cellulose_core.cli` exposes it as
`--charmm-gui`. No scientific reference file is modified.

The internal implementation of CHARMM-GUI's recognizer is not part of this
repository, so this report does not claim a specific internal algorithmic bug.
The evidence supports an input-recognition ambiguity involving explicit
hydroxyl-H geometry and residue direction in this densely packed crystalline
system.

## Automated regression coverage

The test suite now checks:

- exactly 360 residues and 7,614 atoms in standard unmodified 18 x 20 output;
- intact C6 alcohol chemistry and absence of H63 in every unmodified residue;
- explicit inspection of even residues in chain 13;
- deterministic PDB output and correct C6 connectivity;
- rejection of an injected 6-deoxy/H63 defect;
- a fast multi-chain parity regression;
- removal of hydroxyl H, but not O6/H61/H62, in CHARMM-GUI input;
- reversal of whole residue blocks and explicit `O4(i)-C1(i+1)` connectivity;
- 60 O61/O62 carboxylates, 300 intact O6 groups, and no H63 in the TOCNF25
  CHARMM-GUI profile; and
- existing oxidation reproducibility, geometry, charge, terminal chemistry,
  PDB formatting, and crystallographic checks.

Command:

```bash
python -m unittest discover -s tests -v
```

Result at release: 17 tests passed.

## Recommended usage

Generate a normal all-atom PDB for standalone visualization or analysis by
omitting `--charmm-gui`. For CHARMM-GUI preparation, use:

```bash
python builder.py --dp 20 --preset 18 --charmm-gui \
  -o outputs/cnf_18x20_charmm_gui.pdb
```

On upload, select CHARMM input format, retain the explicit connectivity, and
verify that every linkage is beta-(1→4) before generating the PSF. Normal
force-field minimization and equilibration are still required before a
production simulation.
